# KawnGraph Site

Landing page for KawnGraph, the local-first Agent Context Graph for software projects.

## Preview

Open `index.html` directly, or serve the folder with any static server.

```bash
npx serve .
```

## Deploy

This site is static and works on GitHub Pages, Vercel, Netlify, or any static host.

For GitHub Pages:

1. Push these files to `main`.
2. Open repository settings.
3. Go to Pages.
4. Set source to `Deploy from a branch`.
5. Choose `main` and `/root`.
